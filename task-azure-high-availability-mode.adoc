= Azure에서 Cloud Volumes ONTAP 에 대해 고가용성 모드 활성화
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Cloud Volumes ONTAP HA 쌍에 대해 Microsoft Azure의 고가용성(HA) 모드를 활성화하여 예기치 않은 장애 조치 시간을 줄이고 NFSv4를 지원하십시오. 이 모드는 예기치 않은 장애 조치 시 CIFS 및 NFSv4 클라이언트에 대해 60초의 복구 시간 목표(RTO)를 제공할 수 있습니다.

Cloud Volumes ONTAP 9.10.1부터 Microsoft Azure에서 실행되는 Cloud Volumes ONTAP HA 쌍의 예기치 않은 장애 조치 시간을 단축하고 NFSv4 지원을 추가했습니다. Cloud Volumes ONTAP에서 이러한 개선 사항을 사용할 수 있도록 하려면 Azure 구독에서 HA 기능을 활성화해야 합니다.

.이 작업에 관하여
NetApp Console은 Azure 구독에서 이 기능을 활성화해야 할 때 프롬프트를 표시합니다. 다음 사항에 유의하십시오.

* 이 기능은 ONTAP과 연동하여 예기치 않은 장애 조치 중에 NFS 클라이언트가 경험하는 애플리케이션 중단 시간을 줄여줍니다. 이 기능을 활성화한다고 해서 Cloud Volumes ONTAP HA 쌍의 가용성에 문제가 있는 것은 아닙니다.
* 이 Azure 기능을 활성화해도 Cloud Volumes ONTAP HA 쌍에는 영향을 미치지 않습니다.
* Azure 구독에서 이 기능을 활성화해도 환경의 다른 VM이나 동일 구독 내의 단일 노드 시스템에는 영향을 미치지 않습니다.
* 장애 조치 중에 Cloud Volumes ONTAP은 CIFS 및 NFS 클라이언트에 서비스를 제공하는 클러스터 및 SVM 관리 LIF를 위해 내부 Azure 로드 밸런서를 사용합니다.
* HA 모드를 활성화하면 콘솔이 12시간마다 시스템을 스캔하여 내부 Azure 로드 밸런서 규칙을 업데이트합니다.


.단계
_소유자_ 권한이 있는 Azure 사용자로 Azure CLI를 사용하여 해당 기능을 활성화하십시오.

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["Azure Portal에서 Azure Cloud Shell에 액세스"^]
. 고가용성 모드 기능을 등록하세요:
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. 선택적으로 해당 기능이 등록되었는지 확인하세요.
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
Azure CLI는 다음과 유사한 결과를 반환해야 합니다.

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----

== 프라이빗 클라우드 모드에서 Cloud Volumes ONTAP 배포

프라이빗 모드 배포 옵션을 사용하면 조직의 보안 및 규정 준수 요구 사항을 충족할 수 있습니다.  프라이빗 모드 배포는 표준 모드 배포와 동일한 절차를 따릅니다.  공용 인터넷 연결 없이 자체 가상 사설 클라우드(VPC) 또는 가상 네트워크(VNet)에서 작동합니다.

프라이빗 모드에서는 용량 기반 BYOL(Bring-Your-Own License) 또는 link:concept-license-management.html["바이올"] _Essentials_ 패키지를 NetApp에서 구매하고 배포 중에 시스템에 할당해야 합니다. 사용한 용량 중 처음 500GiB는 라이선스 비용에 포함되지 않습니다. 워크로드 요구 사항이 증가함에 따라 Essentials 패키지를 추가로 구매하십시오. 배포 후 콘솔에서 라이선스 일련 번호를 확인할 수 있습니다.

프라이빗 클라우드 모드 배포에 라이선스 파일을 업로드하는 방법에 대한 자세한 내용은  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-manage-node-licenses.html["Cloud Volumes ONTAP의 노드 기반 라이센스 관리"]을 참조하십시오.

.노드 기반 라이선스에 대한 제한 사항
이전의 프라이빗 모드 배포에서는 노드 기반 라이선스만 사용되었습니다. NetApp은 특정 경우를 제외하고 이전 세대 라이선스의 구매, 연장 및 갱신을  https://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/whats-new.html#restricted-availability-of-byol-licensing-for-cloud-volumes-ontap["2025-06-25"]부터 제한해 왔습니다. 노드 기반 라이선스를 사용하는 기존 프라이빗 모드 배포가 있는 경우 용량 기반 라이선스로 전환해야 합니다. 자세한 내용은  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-convert-node-capacity.html["노드 기반 라이선스를 용량 기반 라이선스로 변환"^]을 참조하십시오.

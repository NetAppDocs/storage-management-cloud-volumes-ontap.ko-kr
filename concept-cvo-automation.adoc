= Cloud Volumes ONTAP 자동화 옵션에 대해 알아보십시오.
:hardbreaks:
:allow-uri-read: 
:nofooter:

[role="lead"]
DevOps 팀은 데이터 센터 런타임 환경의 설정 및 관리를 자동화하기 위해 다양한 툴을 사용합니다. NetApp Console 외에도 NetApp Console API, ONTAP CLI 프로시저, Ansible 및 Terraform과 같은 자동화 툴 등 Cloud Volumes ONTAP 자동화에 사용할 수 있는 여러 기술이 있습니다. 이러한 외부 자동화 툴은 일반적으로 IaC(Infrastructure as Code) 설계를 기반으로 합니다.

 https://labondemand.netapp.com/["Lab on Demand"^]를 사용하여 Cloud Volumes ONTAP 자동화를 연습하십시오.



[[netapp-console-apis]]
== NetApp 콘솔 API

NetApp Console은 Cloud Volumes ONTAP 리소스를 프로그래밍 방식으로 관리하는 데 사용할 수 있는 REST API를 제공합니다. 이러한 API는 Amazon Web Services(AWS), Microsoft Azure(Azure) 및 Google Cloud에서 Cloud Volumes ONTAP 시스템 생성 및 관리, 애그리게이트와 볼륨 추가 등의 작업을 지원합니다. 사용 가능한 API 호출은 클라우드 공급자와 배포 유형(단일 노드 및 고가용성(HA) 구성 포함)에 따라 다릅니다.

Cloud Volumes ONTAP API 워크플로를 사용하여 일반적인 배포 및 후속 스토리지 관리를 자동화할 수 있습니다. 일부 워크플로에는 배포 준비, 시스템 생성 및 스토리지 관리가 포함되며, AWS, Azure 및 Google Cloud에 대한 공급자별 워크플로도 제공됩니다.

[[ontap-cli]]
== ONTAP CLI

ONTAP CLI를 사용하여 여러 Cloud Volumes ONTAP 관리 작업을 수행할 수 있습니다. 사용 가능한 절차 및 명령은 기능 및 클라우드 공급자에 따라 다릅니다. ONTAP CLI 또는 ONTAP System Manager를 사용하여 Cloud Volumes ONTAP를 업그레이드하지 마십시오. NetApp Console에서 업그레이드를 수행하십시오.

|===
| 활동 | CLI 절차 또는 명령 | 참고 자료

link:task-aws-key-management.html["AWS KMS 키 관리 구성"] link:task-azure-key-vault.html["Azure Key Vault 키 관리 구성"] link:task-google-key-manager.html["Google Cloud KMS 키 관리 구성"]

| 데이터 손실 이벤트 발생 후 문제가 해결될 때까지 데이터 액세스를 차단하도록 NVFAIL 동작을 구성하십시오. | ONTAP CLI의 NVFAIL 구성 명령 | link:concept-write-speed.html["NVFAIL 구성"]

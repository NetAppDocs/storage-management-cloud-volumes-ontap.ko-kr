=== 프라이빗 모드 배포를 위한 Google Infrastructure Manager 지원

Cloud Volumes ONTAP 9.16.1 이상은 이제 Google Cloud의 새로운 프라이빗 모드 배포에서 https://docs.cloud.google.com/deployment-manager/docs/deprecations["Cloud Deployment Manager"^] (DM) 대신 https://docs.cloud.google.com/infrastructure-manager/docs/overview["Google Cloud Infrastructure Manager"^] (IM)을 지원합니다. Google은 보다 고급 인프라 서비스인 Infrastructure Manager를 위해 Deployment Manager를 더 이상 사용하지 않을 예정입니다.

2026년 2월 25일부터 Cloud Volumes ONTAP은 신규 및 기존 프라이빗 모드 배포에 Infrastructure Manager를 사용합니다. 기본 워크플로는 시나리오에 따라 다릅니다:

[cols="1,4,1,1,1,1"]
|===
| 시나리오 | 행동 | 에이전트용 새 API | 에이전트에 대한 새로운 권한 | Cloud Volumes ONTAP용 새로운 Google Cloud API | 문서 리소스 


| 비공개 모드의 기존 에이전트 및 기존 배포 | NetApp 지원 사이트에서 설치 프로그램을 다운로드하여 Console 에이전트를 최신 버전으로 업그레이드한 다음 호스트에 에이전트를 수동으로 설치하여 Infrastructure Manager API를 사용할 수 있도록 하십시오. 그런 다음 기존 Cloud Volumes ONTAP 시스템을 Infrastructure Manager를 사용하도록 변환하십시오.  a| 
* Cloud Infrastructure Manager API
* 클라우드 할당량 API
* Cloud Build API

 a|

| 새 에이전트 및 새 배포 | 새 에이전트를 생성하고 프라이빗 모드로 새 Cloud Volumes ONTAP 시스템을 배포합니다. |  |  |   a| 
* https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-google-gcloud.html["Google Cloud에서 Console 에이전트를 생성합니다."^]

|===
프라이빗 모드 배포에서는 Cloud Volumes ONTAP이 Infrastructure Manager를 사용하기 시작하도록 몇 가지 구성을 변경해야 합니다.  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/reference-networking-gcp.html#infrastructure-manager-configuration-in-private-mode-or-protected-environments["프라이빗 모드 또는 보호 환경에서의 Infrastructure Manager 구성"^]을(를) 참조하십시오.
